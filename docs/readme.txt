■ これは何か

Splice や自分のフォルダのドラムなどのサンプルを、探して、試聴して、
Pro Tools に挿した Native Instruments の Battery 4 のセルへ読み込むアプリです。
読み込むときは、マウスでドラッグする操作をアプリが代わりに行い、
読み込めたかどうかを読み上げます。
VoiceOver とキーボードだけで使えるように作っています。
名前の「PT」は Pro Tools のことです。

■ 動く環境

- Apple シリコン（M1 以降）の Mac。macOS 14 以降（作者は 15.7.8 で確かめています）
- Pro Tools（作者は 2026.4.1 で確かめています）
- Native Instruments Battery 4（作者は 4.3.1 で確かめています）
- VoiceOver
- 画面と読み上げは、Mac の言語の設定に合わせて日本語か英語で出ます（マニュアルの 2 章）

■ 入れ方（短く）

1. このフォルダの「PT Battery 4 Loader.app」を、アプリケーションフォルダへ移します
2. 開きます。初めて開くとき、macOS が開くのを止めることがあります。
   開き方は、マニュアルの「3.2 初めて開くとき」にあります
3. システム設定の「プライバシーとセキュリティ」の「アクセシビリティ」で、
   PT Battery 4 Loader を許可して、アプリを開き直します（マニュアルの 3.3）
4. コマンド+カンマの設定で、サンプルのフォルダを登録し、コマンド+O でスキャンします
5. Pro Tools で、読み込む先の Battery 4 の画面を 1 枚だけ開きます

詳しくは「マニュアル.html」（または「マニュアル.txt」）を読んでください。
アプリの中では、コマンド+シフト+K でキー操作の一覧を開けます。

■ 大事なこと

Battery の画面は、いつも 1 枚だけ開いて使います。Pro Tools は複数の
プラグインの画面を同じ位置に重ねて開くため、重なっているとどの Battery に
読み込まれるか見分けられず、別のトラックのセルを上書きしてしまうことが
あります。アプリは、画面が重なっているときは読み込みを中止します。
